### deny_holdout.py behaviour
Installed at `/etc/claude-code/hooks/deny_holdout.py` and used only by the research profile (never registered in the committed project settings). Reads the PreToolUse JSON. Denies if any string in `tool_input` (path, pattern, command) contains: `HOLDOUT_UNSEAL`, a path under the deny list (`deny_paths`, read from `/etc/claude-code/research_freeze.deny.json`), or any path from AGENTS.md rule 5 (`.claude/settings*.json`, `.claude/hooks`, `tests/integrity/`, `tests/test_live_import_isolation.py`, `config/gates.yaml`, `config/research_freeze.yaml`, `research/preregistration/`, `research/charters/`, `research/approvals/`) combined with a write verb (`>`, `>>`, `tee`, `sed -i`, `cp`, `mv`, `python -c ... open(..., 'w')`, `git checkout`/`git restore` of that path), or an ISO date >= `seal_date` appearing in a `data/` path. For every non-matching call it exits 0 with no output. Pre-seal reads of `data/research/eodhd` are not denied. Limits, to be stated in GUARDRAIL_REDTEAM.md: it matches command text only. `grep -r` and Python scripts reading directories without naming them are stopped only by the ACL/sandbox (issues #24846, #61208).

### stop_integrity.sh behaviour
Installed at `/etc/claude-code/hooks/stop_integrity.sh` and registered only in the research profile. Contract:
1. Read the hook's stdin JSON. If `stop_hook_active` is true, exit 0 (the hook blocks at most once per turn, so a persistent failure cannot loop).
2. Exit 0 immediately unless `realpath(CLAUDE_PROJECT_DIR)` is under `/local/store/research/ai-trading-system/.claude/worktrees/` (the research clone, PLAN.md section 8; worktrees are never created inside the live checkout, whose refs the services run from). In the live checkout (where ops sessions run, and whose `.venv` is the live interpreter) the hook never runs tests and never blocks.
3. Resolve the interpreter in this order: `<worktree>/.venv/bin/python`, then the shared research venv `/local/store/research-venvs/<depset>/bin/python` (PLAN.md section 8; `<depset>` read from the worktree's `.research-depset` file written by `scripts/new_research_worktree.sh`, default `core`); run with `PYTHONPATH=<worktree>/src` and verify `python -c "import firm,sys; sys.exit(0 if firm.__file__.startswith('<worktree>/src') else 1)"`. Explicitly refuse any interpreter whose realpath is `/local/store/git/ai-trading-system/.venv/bin/python*`.
4. If no safe interpreter is found: in the research profile (the research unix user) exit 2 with instructions on stderr (fail closed); only an ops session may skip, and every skip is appended to a durable log (`/var/log/claude-research/stop_hook_skips.log`) that the red-team review checks.
5. Run `nice -n 10 pytest -q tests/integrity -x` under a timeout (under 120 s). Claude Code blocks a Stop only on exit code 2 (or JSON `{"decision":"block","reason":...}`); pytest exits 1 on failure, which would be a non-blocking error. So the script maps ANY pytest failure or timeout to `exit 2` with the failure summary on stderr, and exits 0 on success.

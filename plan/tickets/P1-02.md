## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
Source formulas, kept exactly:
- `SE = sqrt((1 - skew*SR + (kurt-1)/4 * SR^2) / (T-1))`, raw kurtosis (normal = 3).
- `PSR(SR*) = Phi((SR - SR*) / SE)`.
- `E[max SR] = sqrt(var_sr) * ((1-g) * Phi^-1(1 - 1/N) + g * Phi^-1(1 - 1/(N*e)))`, `g = 0.5772156649`.
- `DSR = PSR(SR* = E[max SR])`.
- `MinTRL = 1 + (1 - skew*SR + (kurt-1)/4 * SR^2) * (Phi^-1(1-alpha) / (SR - SR*))^2` (in observations of the input frequency; convert to years outside).

Corrections and additions (each explained):
- The radicand `1 - skew*SR + (kurt-1)/4*SR^2` can be <= 0 for extreme skew; legacy code floors it at 1e-12 (`max(1e-12, ...)`). New code raises `DegenerateInputError` with the values, rather than clamping silently. The equivalence tests compare only where the radicand is positive.
- No sentinels: `n_obs < 2` -> raise (legacy returned 0.0 for `n < 8`; a separate `n_obs < 8` WARNING is logged because moments are unreliable).
- `dsr` with `var_sr <= 0` or `n_trials < 2` raises instead of returning PSR(0). A single-trial family is not "deflation-free"; the caller must supply N and a positive variance (gates.yaml defines the sources).
- `check_per_period`: if `abs(sr) > 0.5` (a per-period daily Sharpe above 0.5 is about 8 annualised, implausible) raise `SharpeUnitsError("looks annualised")`. If `0.25 < abs(sr) <= 0.5` log a WARNING. The threshold is a keyword so weekly/monthly users can relax it explicitly. The source test "annualisation-mixing guard warns" is met by the warning band; the hard raise is a stricter, documented addition.
- `moments()` uses the same estimators as legacy for like-for-like equivalence: population skew and raw kurtosis over the ddof=1 sd (matches `overfitting.py` L184-186), documented, so the equivalence test is exact. A flag `exact_moments=True` (ddof-corrected) is NOT added; keep one convention.
- `expected_max_sr` uses `_norm_ppf` (Acklam, relative error about 1.15e-9) so it matches legacy; the paper-example tests use tolerance 1e-3 as in the source.

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_sharpe_stats.py`:
- `test_psr_matches_legacy_probabilistic_sharpe`: for 50 seeded return series (n from 60 to 2000, mixed skew/fat tail), `psr(*moments(r)[:1], 0.0, n, skew, kurt)` equals `probabilistic_sharpe(r, 0.0)` to 1e-12; also with `sr_star != 0`.
- `test_dsr_matches_legacy_deflated_sharpe`: build `trial_sharpes` (N=2..300, positive variance) and `r`; `dsr(sr, n, skew, kurt, len(trials), var(trials, ddof=1))` equals `deflated_sharpe(r, trials)` to 1e-12. Also covers the `prior_trials` path: legacy `prior_trials=k` equals `dsr(..., n_trials=len(trials)+k, var_sr=var(trials))`.
- `test_paper_examples_1e_3`: hard-code the published Bailey and Lopez de Prado (2014) numerical example: `expected_max_sr(100, 0.5/250) ~= 0.1132` and `dsr(2.5/sqrt(250), 1250, -3, 10, 100, 0.5/250) ~= 0.9004` (N=100, per-period var of SR 0.5/250, T=1250, annual SR 2.5, skew -3, raw kurtosis 10), both at tolerance 1e-3 (a scratch recomputation of the formulas gives SR0 = 0.113172 and DSR = 0.900397). Add the PSR worked example from Bailey and Lopez de Prado (2012) the same way, with the published value transcribed by the human reviewer from the paper. No self-referential fallback: do not derive expected values from the code under test.
- `test_expected_max_sr_monte_carlo`: simulate max of N iid N(0, var) Sharpe estimates (N in {10, 100, 1000}, 20000 reps, fixed seed): mean is within 5% of `expected_max_sr(N, var)` (source test).
- `test_min_trl`: closed-form check at `SR=0.5/sqrt(252)`-style per-period values: `min_trl` equals the formula; monotone decreasing in SR, increasing in |skew| for negative skew; about 11 years for annual SR 0.5, SR*=0, normal returns, alpha 0.05 (source B0 figure; tolerance 15% because the source says "approx.").
- `test_length_adjusted_var_sr`: K iid null series with very different lengths T_i give `length_adjusted_var_sr` within Monte Carlo error of `sr_sampling_var(0, n_obs_cand)` (the cross-trial excess is about 0), while the unadjusted `var(SR_i)` is inflated by the short series; the floor is honoured; `sr_sampling_var` matches the Mertens formula by hand at 1e-12.
- `test_dsr_raises_on_degenerate`: `n_trials=1`, `var_sr=0`, `n_obs=1` each raise `DegenerateInputError`; `dsr` never returns `psr(…, 0)` silently.

## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
- **Groups:** order samples by `t0`; cut into `N` contiguous groups of near-equal size (`np.array_split`).
- **Purge (source rule, kept):** drop from train any sample whose label interval `[t0, t1]` overlaps the test block's `[min t0, max t1]`. For CPCV the test set is the union of `k` groups; purge against EACH test group's interval separately (the groups are not contiguous).
- **Embargo (source rule, kept):** after each test block, also drop the next `embargo_pct * T` samples (by position in time order) from train. For CPCV apply after each test group that is followed by a train group.
- **Paths:** `phi = C(N,k) * k / N` (N=10, k=2 gives 45*2/10 = 9). Each group appears as a test group in `C(N-1, k-1)` = 9 splits. `backtest_paths` assigns, for each group, its `phi` out-of-sample prediction blocks (one per containing split) to paths 0..phi-1 in split order, then concatenates groups in time order, so every path is a complete OOS series covering the whole sample. `fold_predictions[split_id]` holds the OOS predictions/returns for that split's test samples (concatenated test groups in time order); the function splits them back per group. Validate that all `phi` paths have equal length and cover each sample exactly once; raise otherwise.
- **Use restriction (source DO NOT, restated):** CPCV here is for ML components and for robustness reporting on the small pre-registered grid; it is not a search tool for trend parameters.
- Determinism: no randomness anywhere; split order is `itertools.combinations` order.

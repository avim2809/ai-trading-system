## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
Notation: `d_k,t` performance differential, `dbar_k = mean_t d_k,t`, `T` rows, `B` bootstrap draws. One set of stationary-bootstrap index paths is generated and reused across the three procedures when called together (internal helper) so results are comparable; each public function is independently seeded.
- **White RC (source: "RC max t"):** statistic `V = max_k sqrt(T) * dbar_k` (White's original) and the studentised variant `max_k sqrt(T)*dbar_k / omega_k`. The source says RC uses max t; implement the studentised max t as default (`studentise=True`) and expose `studentise=False` for White's raw form. Bootstrap: `V*_b = max_k sqrt(T) * (dbar*_k,b - dbar_k)` (recentred at the sample mean), `p = (1 + #{V*_b >= V}) / (1 + B)`. RC is known to be conservative with poor/irrelevant alternatives; this is why SPA is also reported.
- **Hansen SPA (source: "studentised with recentring"):** `T_SPA = max(0, max_k sqrt(T)*dbar_k/omega_k)`. `omega_k^2` is the bootstrap variance of `sqrt(T)*dbar*_k` (or the Newey-West/Politis-Romano estimate). Recentring: `mu_c,k = dbar_k * 1{ sqrt(T)*dbar_k/omega_k <= -sqrt(2 log log T) }` (consistent), `mu_l,k = min(dbar_k, 0)` (lower), `mu_u,k = 0` (upper, equals RC). Bootstrap statistic `T*_b = max(0, max_k sqrt(T)*(dbar*_k,b - dbar_k + mu_k)/omega_k)`; `p_i = (1 + #{T*_b > T_SPA}) / (1 + B)` for i in {lower, consistent, upper}. Report the consistent p as `p_consistent` (the headline) and all three.
- **Romano-Wolf stepdown (source: "stepdown on max t"):** t-stats `t_k = sqrt(T) dbar_k / omega_k`. Sort descending by signed `t` (one-sided) or `|t|` (two-sided): order `(1) >= ... >= (K)`. Bootstrap recentred t-stats `t*_k,b = sqrt(T)(dbar*_k,b - dbar_k)/omega_k`, dividing BOTH `t_k` and `t*_k,b` by the same full-sample `omega_k` (the bootstrap std of `sqrt(T)*dbar*_k` computed once over all B draws); do not use a per-bootstrap-sample `omega*_k` unless a per-sample Politis-Romano variance estimator is specified and tested. In the one-sided case sort by SIGNED `t` (descending); the `two_sided` flag sorts by `|t|`. Step j: critical value `c_j = (1-alpha) quantile over b of max_{k in remaining} t*_k,b`; reject `(j)` if `t_(j) > c_j`, otherwise stop. Adjusted p-values `p_adj,(j) = max(p_adj,(j-1), (1 + #{max_{remaining} t*_b >= t_(j)}) / (1 + B))` (monotone). Strong FWER control. One-sided (performance positive); a `two_sided` flag uses `|t|`.
- **Variance estimation:** use the bootstrap-based `omega_k` (std of `sqrt(T)*dbar*_k`) with a floor `1e-12`; a column with zero variance gets `t=0` and is never rejected (no divide-by-zero).
- **Block length:** `None` -> Politis-White (maximum over columns, per P1-07). Never an iid bootstrap (a `block_len=1` is allowed only explicitly and logs a WARNING).
- `B` default 2000 (source). Vectorise over `B` and `K`; memory: do the bootstrap in chunks of at most 256 MB.

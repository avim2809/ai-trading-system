## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
- **p-value:** `p = (1 + #{null >= obs}) / (1 + n)` for right tail (source formula; never exactly 0). Left tail uses `<=`. Two-sided: `min(1, 2*min(p_left, p_right))`. Empty null raises (legacy returns `None`; a silent `None` is how a broken null looks like a result).
- **Stationary bootstrap (Politis-Romano):** `p = 1/mean_block`. For each simulated path: `idx[0] ~ U{0..n-1}`; for t >= 1, with probability `p` start a new block at a fresh uniform index, otherwise `idx[t] = (idx[t-1] + 1) mod n`. Vectorise over simulations (loop over t only, or build block starts with a geometric draw and expand with `np.repeat` + offsets). Series is treated as circular. Block lengths are Geometric(p) with mean `mean_block`.
- **Automatic block length (Politis-White 2004, with the Patton-Politis-White 2009 correction):** compute sample autocovariances `R(k)`; let `m_hat` be the smallest `m` such that `|rho(m+j)| < c*sqrt(log10(n)/n)` for `j=1..K_n` with `c=2`, `K_n = max(5, ceil(sqrt(log10(n))))`, and set the flat-top bandwidth `M = min(2*m_hat, max_lag)` (Politis and White 2004 use `M = 2*m_hat`; `arch.bootstrap.optimal_block_length` does the same; using `M = m_hat` halves the window and biases `G` and `g(0)`, hence `b`, for every consumer: P1-06, P1-10, the charter max-DD procedure, G-DECOMMISSION). Sums run over `|k| <= M`. Flat-top lag window `lambda(k/M)` (trapezoid: 1 for |s|<=0.5, 2(1-|s|) for 0.5<|s|<=1); `G = sum lambda(k/M)*|k|*R(k)`; `D_SB = 2*g(0)^2` with `g(0) = sum lambda(k/M) R(k)` (Patton et al. 2009 form), `b_SB = (2*G^2 / D_SB)^(1/3) * n^(1/3)`. Cap at `min(b, ceil(min(3*sqrt(n), n/3)))` (Politis-White cap) and floor at 1. For multi-series input take the maximum over series (conservative: longer blocks). Verify against `arch.bootstrap.optimal_block_length` values hard-coded in a test as constants from a reference run done OUTSIDE the repo (do not install arch in the live venv). Also test against the analytic AR(1) optimum `b ~ n^(1/3) * (2*rho/(1-rho^2))^(2/3)` for `rho in {0.2, 0.5, 0.8}` at `n=5000`, asserting agreement within a stated tolerance (document it in the test; not just monotonicity).
- **sign_randomisation_null (BLOCK version):** draw ONE random sign per stationary-bootstrap block (mean block `block_len`, default `politis_white_block_length(pnl)`), multiply the strategy's per-period PnL (`positions * returns`) by the block signs, recompute the statistic. Valid under the null of a symmetric, zero-mean return conditional on positions, and robust to autocorrelated PnL (trend and low-turnover strategies). An i.i.d. sign flip (`block_len=1`) understates the variance of the mean for autocorrelated PnL, makes the null too narrow and over-rejects; it is allowed only when passed explicitly and logs a WARNING.
- **phase_randomised_surrogate:** `rfft`, replace phases of bins 1..n/2-1 with `U(0, 2pi)` (keep DC and Nyquist), `irfft`. Preserves the power spectrum (so autocorrelation) and destroys non-linear structure. Mean and variance preserved to numerical error.
- **random_entry_null:** preserve the strategy's exposure profile (number of trades and holding periods) but draw entry dates uniformly at random; recompute the statistic. When `keep_holding_periods=False`, draw lengths from the empirical distribution.

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_nulls.py`:
- `test_p_value_matches_legacy_pattern_p_value`: for random null/obs, `p_value(obs, null, "right")` equals `firm.patterns.significance.pattern_p_value(obs, null)` exactly.
- `test_bh_matches_legacy`: `benjamini_hochberg(p, q)` equals `benjamini_hochberg_accept(p, q)` on 200 random p-vectors incl. empty and ties.
- `test_p_value_uniform_under_null` (source test, tests the rank formula only): 500 runs; each draws an observed statistic and a null of size 199 from the same distribution; the 500 p-values are tested with `scipy.stats.kstest(..., 'uniform')` and `p > 0.01`. Discrete correction: use `n=999` or compare against the discrete uniform grid; document the choice.
- `test_null_generators_uniform_under_H0` (the actual safeguard against the Gann p=1.000 bug; parametrised over `sign_randomisation_null`, `random_entry_null`, `phase_randomised_surrogate` and the block bootstrap): 500 runs on data generated under THAT generator's H0 (symmetric zero-mean PnL for block sign flips; random positions on drift-free returns for random entry; a stationary Gaussian series for the surrogate), compute `p` with `p_value`, assert `kstest(..., 'uniform')` `p > 0.01` AND the share of runs with `p == 1` is < 0.02. A broken generator like Gann's would fail this.
- `test_block_sign_vs_iid_sign_on_ar1`: on AR(1) rho=0.5 PnL under H0 the block version rejects at about alpha (within a stated band) while the i.i.d. version (`block_len=1`) over-rejects.
- `test_power_p_below_005_most_runs` (source test): T=250, true mean 0.5 sd per period, PINNED; `p < 0.05` in >= 80% of 500 runs for the block sign randomisation and random-entry.
- `test_phase_surrogate_preserves_spectrum_mean_var`.
- `test_seed_reproducible_and_different_seeds_differ`.
- `test_empty_null_raises`.
- `test_no_global_rng_state_touched` (`np.random.get_state()` before/after).

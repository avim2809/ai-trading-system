**Phase:** P1 **Status:** EXTEND_EXISTING **Depends on:** P1-01, P0-04, P0-08 **Touches live services:** no **Owner decisions:** OD-13, OD-06

## Rationale (cite source plan / literature)
Source plan P1-09: a pre-registration system where each family's hypothesis, mechanism, universe, date range, exact parameter grid (maximum size), metrics, gates, planned trial count and falsification criteria are fixed and human-approved before any backtest, and `backtest_logged` refuses configurations not covered by an approved prereg except in `exploratory` mode (logged, counted, never promotable). Rationale in the literature: pre-specification limits researcher degrees of freedom (Bailey et al. 2014; Harvey, Liu and Zhu 2016 on multiple testing in factor research).

## Interfaces (Python signatures under src/firm/…)
```python
@dataclass(frozen=True)
class IndexEntry:
    family: str; kind: Literal["frozen_module", "yaml"]
    module_path: str | None; yaml_path: str | None
    fingerprint: str; freeze_commit: str; freeze_time_utc: str
    ledger_path: str | None          # docs/<x>_trial_history.json; None for s2_forward and futures_trend
    fingerprint_source: Literal["trial_history", "freeze_commit", "none"]   # where the recorded fingerprint comes from
    status: Literal["APPROVED","DRAFT","SUPERSEDED","RUN","REJECTED"]
    notes: str = ""

@dataclass(frozen=True)
class PreregSpec:                    # YAML schema for new families
    family: str; hypothesis: str; mechanism_ref: str      # path to approved charter (P5-02)
    universe: list[str]; date_range: tuple[str, str]      # pre-seal only
    param_grid: dict[str, list]; max_grid_size: int       # <= 12 for core_v1
    n_planned_trials: int
    metrics: list[str]; gates_hash: str                   # sha256 of config/gates.yaml
    charter_ref: str; falsification: str
    post_seal_data_declaration: str                       # "No data after 2026-09-30 was examined."
    approver: str; approved_at_utc: str                   # from `date -u`/git

def load_index(path: Path = ...) -> list[IndexEntry]
def spec_hash(spec: PreregSpec) -> str                    # sha256 canonical JSON of all fields except approver/approved_at
def recompute_fingerprint(module_path: str) -> str        # imports module via importlib in a subprocess, calls bars_fingerprint()
def is_approved(prereg_id: str, config: dict) -> bool     # prereg hash approved AND config is within param_grid
def covers(spec: PreregSpec, config: dict) -> bool
def verify_index(index: list[IndexEntry]) -> list[str]    # human-readable problems
```

## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
- **Schema (source list kept):** hypothesis; mechanism; universe; date range; exact param grid (max size); metrics; gates; n planned trials; falsification; approver and time. Additions here: `gates_hash`, `charter_ref`, and the post-seal data declaration (design requirement: every `core_v1` choice is frozen and dated before P3-08 with a declaration that no post-seal data was examined).
- **`is_approved`:** (1) spec exists in INDEX with `status="APPROVED"`; (2) `spec_hash` equals the recorded hash; (3) `gates_hash` equals the current `sha256(config/gates.yaml)`; (4) the config's parameters are in the grid and `len(grid)` expansions do not exceed `max_grid_size`; (5) the charter file exists and its git commit time is EARLIER than the prereg's approval time (G-RESEARCH 8 ordering; checked by CI too). Any failure returns False; `backtest_logged` then raises `UnapprovedPreregError` unless `mode="exploratory"`, where the row is logged and counted but flagged non-promotable.
- **`recompute_fingerprint`:** run in a subprocess with `PYTHONPATH=<worktree>/scripts` so importing a frozen module has no side effects on the parent. The index stores the fingerprint from the family's trial-history file when one records it (`fingerprint_source="trial_history"`, cross-check: they must match). For `combination`, `pattern_ml`, `s2_forward` and `futures_trend` (no recorded fingerprint) it stores the fingerprint recomputed AT THE FREEZE COMMIT (`git show <commit>:<path>` into a temp dir, imported in a subprocess; `fingerprint_source="freeze_commit"`) and `verify_index` asserts it equals the HEAD recomputation (a drift means the frozen file changed after freeze).
- **`verify_index`:** for each frozen module entry: file exists, recomputed fingerprint equals recorded, freeze commit is an ancestor of HEAD; if `ledger_path` is set it exists and its entries' fingerprints (where present) are consistent; if `fingerprint_source="freeze_commit"`, the freeze-commit recomputation equals the HEAD recomputation. The DRAFT futures entry is verified to have `status="SUPERSEDED"` only after the owner decides OD-13.
- Approval workflow: the agent writes the YAML; the owner reviews and commits; CODEOWNERS plus branch protection (OD-06) enforce the review. This ticket does not claim enforcement beyond what OD-06 provides.

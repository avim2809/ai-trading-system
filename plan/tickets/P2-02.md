## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
```
spy = data_access.read_parquet(etfs_full/SPY.parquet, asof=asof)      # calendar source, also sealed
for sym in universe: raw = data_access.read_parquet(etfs_full/sym.parquet, asof=asof)
   raw = raw[raw.date <= asof]               # PIT truncate BEFORE cleaning
   bars, rep = clean_bars_v3(raw, "equity", equity_calendar_v3(spy))
   total return r_t = adj_t/adj_{t-1} - 1 within a segment, NaN across segment starts
CPI is published with a lag: PIT value at asof = latest observation whose publication date <= asof
   (use CBS release lag, documented; if unknown use 45 days, flagged)
```
PIT contract: `load(asof) == clean_bars_v3(raw[date <= asof])`, i.e. truncate first, then clean. Cleaning v2/v3 `_spikes_and_breaks` looks ahead up to 5 bars (bar t is dropped if one of t+1..t+5 reverts), so cleaning the full history and then truncating would leak future information into the decision at `asof`. Consequently the property `load(asof) == load(later_asof)[:asof]` holds only for asof values more than 5 bars past any spike. Full-window cleaning (used for data repair in research runs) carries this known look-ahead of up to 5 bars; the P3-09/P3-11 prereg must document it.

Correction vs source: the source's "back-adjusted = raw away from rolls" test belongs to futures (P2-07). For ETFs the equivalent test is "adjusted_close ratio equals raw close ratio on days without a dividend or split".

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_etf_loader.py` (synthetic fixtures in `tmp_path`, no real data in CI):
- `test_no_lookahead`: bars dated after `asof` never returned; changing a future row does not change output at `asof`.
- `test_dates_monotonic_unique`.
- `test_pit_asof_property` (hypothesis if available from P1-05, else a parametrised loop): for random asof dates more than 5 bars past any spike, `load(asof)` equals `load(later_asof)` truncated to asof.
- `test_spike_lookahead_not_used`: fixture with a spike at asof-2 whose reversal falls at asof+3: the bar is kept at `asof` (reversal not yet visible) and dropped at a later asof. This proves no look-ahead.
- `test_no_double_count_dividends` is owned by P2-05; here `total_return` uses `adjusted_close` only.
- `test_delisted_truncated_and_reported`.
- `test_manifest_roundtrip_and_tamper`: modify one byte, `verify_manifest` returns that path; `snapshot_id` changes.
- `test_seal_blocks_post_seal_asof` (parametrised): asof=2026-10-01 and asof=2026-10-02 raise `HoldoutAccessError`; asof=2026-09-30 succeeds and returns no row dated after 2026-09-30.
- `test_uses_cleaning_v3`: a sentinel bar in the fixture is dropped.
- `test_cpi_publication_lag` (includes the same seal boundary for the IL macro series: asof 2026-10-01 raises, 2026-09-30 succeeds).

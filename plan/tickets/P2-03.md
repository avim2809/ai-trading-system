## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
- Spike: `z_t = r_t / std(r_{t-window..t-1})` using only past returns (no look-ahead); flag if `|z_t| > 8`. Do not delete.
- Stale: run of identical close for more than `max_repeat_days` trading days (also identical volume).
- Missing days: `expected - observed`, minus dates before inception and after delisting; report count and the first 10.
- Negative price: asset in (equity, etf, crypto) with price <= 0 is a flag; for futures it is info and requires an allow-list entry (CL 2020-04-20, close -37.63) in the report.
- FX: `px_usd == px_local * fx` within tolerance, and fx strictly positive with no day-over-day change above 10% without a flag.
- Roll gap: the jump in the raw series on a roll date should be absorbed by the adjustment; flag when the adjusted return on a roll date exceeds `tol_sigma` times the typical adjusted return sigma.
Add a test that QA never modifies its input (frame equality before/after).

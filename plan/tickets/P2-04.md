## Rationale (cite source plan / literature)
Source P2-04: `cost(instrument, qty, price, adv, spread, vol, *, multiplier=1.0) -> CostBreakdown(commission, exchange_fees, half_spread, impact, total)`; IBKR tiered schedule from config; empirical half-spread; impact = k times sigma times sqrt(qty/ADV) with a conservative k; futures roll = two spread crossings per roll; the multiplier scales all components. ## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
```
notional = |qty| * price * contract_multiplier
commission = IBKR tiered/per-share/per-contract schedule from cfg, min and max per order applied
             (Alpaca ETFs: zero commission, regulatory fees SEC/TAF on sells per cfg)
exchange_fees = per-contract/per-share exchange and clearing fees from cfg
half_spread = 0.5 * spread * price * |qty| * cm            # spread from data if given, else empirical_half_spread or cfg default
impact = k * sigma * sqrt(|qty| / ADV) * notional          # source formula; sigma daily, ADV in same unit as qty
roll = roll_spreads_per_roll(=2) * half_spread_per_crossing  # two spread crossings per roll, only when is_roll
total = commission + exchange_fees + half_spread + impact + roll
multiplier m: every component * m   (so 2x stress doubles all)
```
Note the impact term: `k * sigma * sqrt(qty/ADV)` is a fractional price move; multiplying by notional gives currency. State this in the docstring. Conservative k default is set in config, flagged "uncalibrated"; no value is tuned on results. `qty = 0` returns zeros; `adv <= 0` raises (no silent fallback, no flat bps).

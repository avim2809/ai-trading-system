## Rationale (cite source plan / literature)
Source P2-05: informational after-tax model for an Israeli resident: 25% on realised real gains, additional 3% plus 2% surtaxes above ILS 721,560, in-year loss offsets, dividend withholding by fund domicile, FX translation to ILS. A passive benchmark (60/40 or global equity) runs through the same tax model with annual rebalancing costs. Output: pre-tax, after-cost, after-tax CAGR, vol, Sharpe and max drawdown for system, benchmark and the difference with a bootstrap CI. G-RESEARCH 7 compares after-tax, after-cost Sharpe with the benchmark. Information only, not tax advice.

## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
```
for each sell lot (FIFO unless config says otherwise):
    real_gain_ils = proceeds_ils - basis_ils * (cpi_sell / cpi_buy if inflation_adjust else 1)
losses offset same-year gains; unused loss carried forward if enabled
tax_year = 0.25 * max(0, net_real_gain) + surtax on annual taxable income above threshold
   (3% on the part above ILS 721,560, plus an additional 2% on capital income above it, per source plan; verify)
dividends: withholding by domicile first, then Israeli tax with foreign-tax credit if cfg allows
tax convention fixed ex ante (NOT a free switch): accrue tax daily against a deferred-tax liability on unrealised real gains (mark-to-market after-tax NAV); terminal liquidation reported as a sensitivity only.
   Both conventions live in config/tax_il.yaml, are referenced by hash in the core_v1 prereg and gates.yaml, and are applied identically to system and BM2 (BM2 defers far more gains than a trend system, so choosing them after seeing results would move gate 7).
benchmark: same function on BM2 trades (annual rebalance for the gate; monthly as sensitivity) with costs from firm.costs.model
CI: PAIRED stationary bootstrap. Per replicate draw ONE set of Politis-White block indices and apply it to the aligned bivariate (system, BM2) daily return series; compute SR_sys - SR_bm, dCAGR and dMaxDD on each replicate. The CI is on SR(a) - SR(b), NOT the Sharpe of the daily difference series a-b (an information ratio, a different quantity; gate 7 and P3-08's power analysis need the Sharpe gap). Recorded seed, 10,000 draws. Optional cross-check: Ledoit-Wolf (2008) studentised Sharpe-difference test.
```
Correction note: the source says "annual rebalancing costs" for the benchmark, and the reconciled plan keeps that for the gate (the earlier design's monthly default is now the sensitivity), so the gate's cost line is annual. Costs enter before tax (they reduce gains).

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_after_tax.py` (synthetic data):
- `test_single_trade_hand_computed`: buy 100 at 100, sell at 150 with flat CPI and FX, 25% on 5000 gives tax 1250 exactly.
- `test_inflation_adjusted_basis`: with 20% CPI rise, the taxable gain falls by the basis uplift.
- `test_loss_offset_same_year_and_carryforward`.
- `test_surtax_only_above_threshold`: income below threshold pays none; just above pays 3% (and 2% layer) on the excess only.
- `test_fx_translation_gain_in_ils_when_usd_rises`.
- `test_withholding_us_vs_ie_domicile_differs`.
- `test_after_tax_never_exceeds_pre_tax_total_return`.
- `test_benchmark_bm2_annual_rebalance_weights` (default) and `test_benchmark_bm2_monthly_rebalance_weights` (sensitivity), cost deducted in both; `test_gate_benchmark_is_higher_after_tax_variant`.
- `test_bootstrap_ci_reproducible_with_seed` and `test_ci_uses_block_not_iid` (autocorrelated fixture gives wider CI than an iid resample).
- `test_ci_centred_on_sharpe_gap_not_ir`: fixture where SR(a-b) differs clearly from SR(a)-SR(b); the CI is centred on SR(a)-SR(b).
- `test_paired_resample_uses_same_indices` (both legs use the same resampled indices).
- `test_tax_conventions_identical_for_system_and_bm2` and `test_buy_and_hold_end_nav_includes_deferred_liability`.
- `test_no_double_count`: with tax and costs off, NAV from price plus reinvested dividends equals the adjusted_close total-return NAV within 1e-6.
- `test_compare_returns_gross_after_cost_after_tax_states`.
- `test_core_only_100_sanity`: pre-tax BM2 CAGR over 2015-02-02..2026-09-28 is within 1 percentage point of 8.66% only when run with real data; opt-in only: marked `@pytest.mark.real_data`, deselected by default (addopts/conftest) so it never adds an un-ledgered real-data backtest to the mandatory full-suite runs on the live host; run only by an owner-triggered, niced command, with data access through `etf_loader`/`data_access`. Skip when data is absent via `pytest.mark.skipif(not Path('data/research/eodhd/etfs_full/SPY.parquet').exists(), reason='licensed data absent')` (not `importorskip`, which only checks module importability).
Acceptance: green suite (real_data test excluded by default); summary table prints assumptions used.

## Rationale (cite source plan / literature)
Source plan P3-01 and Carver, *Systematic Trading* / *Advanced Futures Trading Strategies*: every forecast and position size is scaled by an annualised volatility estimate. A fast EWMA (span 35) is blended 70/30 with the long-run average of that same vol, and floored, so that vol does not collapse in quiet periods and over-lever the book. Source A5 (vol targeting is a strong-evidence result) is why this estimator feeds EWMAC (P3-02), breakout scaling (P3-03), sizing (P3-06) and the vol-targeting limits (P4-03). The ticket is code and synthetic fixtures only. Real-data use is P3-11.

## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
Source formula, kept: `ewma_vol(returns, span=35, blend_long_weight=0.3, long_window_days=2520)`; EWMA std blended 70/30 with the long-run average; floored at the 5th percentile of history; annualised.

```
fast_t   = sqrt(EWMA_span(r^2)_t)            # pandas ewm(span=35, adjust=False) on r**2, zero-mean (Carver)
                                              # (document: zero-mean vs demeaned; zero-mean chosen, fixed)
long_t   = mean(fast_{t-L+1..t}) once t >= L-1, else expanding mean(fast_{..t})   # L = 2520
blend_t  = (1 - 0.3) * fast_t + 0.3 * long_t
floor_t  = quantile_{0.05}(blend_{..t})       # EXPANDING quantile, uses only data up to t
vol_t    = max(blend_t, floor_t) * sqrt(256)
```
Corrections and additions, each with a reason:
- The source says "floor at 5th percentile of history". A full-sample percentile would use future data. The floor MUST be an expanding quantile (`expanding_percentile_floor`), computed on data up to and including t only. This is stated as a correction, and the no-look-ahead test enforces it.
- The vol known at the close of day t uses return t. Any consumer that trades at t+1 must lag by one bar. The lag is the consumer's job (P3-09), and `ewma_vol` never shifts internally. This is documented in the docstring, and P3-09 owns the shift test.
- 256 trading days per year (Carver) is used instead of 252, in a single exported constant, so that P3-02/P3-06 and the charter use the same annualisation. The conversion to 252 for reporting Sharpe stays in `firm.validation`.
- The 2520-day long window, `min_obs=256` and the percentile floor all count VALID (non-NaN) return observations, not index rows. A test pins this.
- Missing days (holidays, halted ETFs) produce NaN returns. They are skipped by the EWMA (`ignore_na=True`), never forward-filled to zero, to avoid biasing vol down.

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_signals_vol.py` (synthetic and hand-computed only; no files under `data/`):
- `test_hand_computed_small_case`: a 6-point return series with `span=3`, `blend_long_weight=0`, no floor reproduces a hand-computed EWMA std to 1e-12 (the expected values are written in the test as literals with the derivation in a comment).
- `test_blend_70_30`: with constant-vol synthetic returns after a vol step, `vol` equals `0.7*fast + 0.3*long` (computed independently in the test) to 1e-12.
- `test_no_lookahead`: compute `vol` on the full series. For 20 random cut points `k`, recompute on `returns[:k+1]`. `vol[k]` is identical, so a later spike cannot change an earlier estimate. This also covers the expanding floor.
- `test_floor_is_expanding_not_global`: a series with a late low-vol regime shows the early floor unchanged after the regime is appended.
- `test_warmup_expanding_until_2520`: for `n < 2520` the long component equals the expanding mean. At `n == 2520` it switches to the rolling window. Estimates are NaN before `min_obs=256`.
- `test_nan_returns_skipped_not_zeroed`: the vol computed on a series with NaN holiday rows equals the vol computed on the same series with those rows removed, to 1e-12 on the shared dates (`ewm(ignore_na=True)`). Forward-filling or zero-filling the NaNs must fail this test.
- `test_scale_annualisation`: iid N(0, 0.01^2) daily returns, 20000 days, give vol within 5% of `0.01*16`.
- `test_price_unit_vol`: matches `price*vol/16` on a fixture.
- `test_import_light`: importing `firm.signals.vol` in a subprocess does not import `firm.live`, `firm.api`, `firm.runtime`.
- `tests/test_live_import_isolation.py` (P0-06) still passes with the new module present.

## Rationale (cite source plan / literature)
Source plan P3-03 and Carver's breakout rule (a smoothed position of price inside its rolling range). ## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
Source formula, kept: `forecast = 40 * (price - rolling_mid_N) / (rolling_max_N - rolling_min_N)`, smoothed with an EWMA of span N/4, scaled so that the average |f| = 10, N in {20, 40, 80, 160, 320}.

```
mx_t  = rolling_max(price, N)          # window includes t, min_periods = N
mn_t  = rolling_min(price, N)
mid_t = (mx_t + mn_t) / 2
raw_t = 40 * (price_t - mid_t) / (mx_t - mn_t)       # in [-20, +20] by construction
raw   = ewm(raw, span = max(1, N // 4), adjust=False).mean()
f     = clip(raw * scalar, floor, cap)
```
Clarifications:
- `40*(price-mid)/(max-min)` lies in [-20, +20] by construction, so the scalar is close to 1 before the smoothing shrinks it. The scalar is therefore estimated, never assumed.
- A zero range (`max == min`, e.g. a halted or flat series) gives raw 0 with a DEBUG-level count in the return of a helper, not a silent divide-by-zero. The test covers it.
- Rolling windows are trailing and include t. The forecast at close t is traded at t+1 by P3-09.
- Spans: `N // 4` as an integer, with a floor of 1. For N=20 this gives span 5.
- No vol input is needed for the raw forecast, which is a deliberate difference from EWMAC. Vol enters only at sizing (P3-06).

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_signals_breakout.py` (synthetic only):
- `test_hand_computed`: a 6-bar price series with `N=4`, no smoothing, reproduces hand-computed values (literals in the test) to 1e-12.
- `test_range_bounds`: unsmoothed raw lies in [-20, 20] for 100 random-walk paths.
- `test_sign_trend_and_reversal`: an uptrend gives f > 0 and a downtrend f < 0. After a trend reversal, the sign flips after a lag that increases with N.
- `test_zero_range_is_zero_not_nan`: a flat series gives raw 0, with no inf or NaN after the warm-up.
- `test_smoothing_span_is_n_over_4`: for N in the set, an impulse response matches `ewm(span=N//4)`.
- `test_pooled_scalar_gives_avg_abs_10`: using `estimate_pooled_scalar` across synthetic instruments gives the pooled mean |f| equal to 10.
- `test_no_lookahead`: f at k is identical on `price[:k+1]`.
- `test_cap_and_floor`: caps and the optional floor parameter work (the ETF path leaves per-rule floors off).
- `test_unrelated_to_volatility_breakout`: `firm.signals.breakout` does not import `firm.strategies` (checked in a subprocess).

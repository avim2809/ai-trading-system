## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
Source formula, kept: annualised carry `= (price_near - price_far) / (delta_t in years)` divided by annualised sigma_price; smoothed with an EWMA of spans {5, 20, 60, 120}; scaled to average |f| = 10.

Clarifications and one sign convention:
- `price_near - price_far > 0` is backwardation (positive carry for a long). The test fixtures fix the sign.
- `sigma_price_annual` is in PRICE units per year (`price * vol_annual`), so the ratio is a dimensionless annualised carry per unit of vol. The caller must not pass `sigma_price` in daily units. A unit guard (raises when the median ratio looks like a daily scale, `abs(median) < 1e-4`) is NOT added because it would be a heuristic. The docstring and a test state the convention instead.
- `years_between` must be positive and comes from actual expiry dates, not a fixed month count. Rolls must not look ahead: near/far are the contracts the rule would be holding at t, which is P2-07's responsibility. The function states that precondition.
- Forecast scalar is a parameter, estimated only in P3-11 if and when a futures family is pre-registered.

## Tests & acceptance criteria (concrete test file names and assertions)
`tests/test_signals_carry.py` (fixtures only; no data files):
- `test_backwardation_positive`: `price_near > price_far` gives a positive forecast. Contango gives a negative one (source test).
- `test_hand_computed`: near 105, far 100, 0.25 year, sigma 10 per year, so raw = (5/0.25)/10 = 2.0, matched to 1e-12.
- `test_longer_gap_lower_carry`: the same price spread over a longer `years_between` gives a lower |carry| (annualisation works).
- `test_rejects_nonpositive_years`: `years_between <= 0` raises `ValueError`.
- `test_smoothing_spans`: an impulse response matches `ewm(span=s)` for s in {5, 20, 60, 120}.
- `test_cap_floor_and_scalar`: caps and floors hold, and the long/flat floor works.
- `test_no_lookahead`: forecast at k is identical on a truncated input.
- `test_import_light` (subprocess): no `firm.live`, `firm.api`, `firm.runtime`, `firm.research`.

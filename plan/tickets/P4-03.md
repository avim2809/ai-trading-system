## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
1. Raw weights come from P3-06, which already sizes each position in proportion to its forecast at tau. This module must NOT renormalise the portfolio to tau on every call (that would erase forecast proportionality and apply tau twice).
2. Vol-target scalar (source rule): `s = clip(tau / sigma_ewma, upper=max_vol_scale)` with `max_vol_scale = 1.5`, where `sigma_ewma` is the slow EWMA (`vol_ewma_span`) of the realised returns of the forecast-sized portfolio. `sigma_ewma` is supplied by the caller (the P3-09 vector engine computes it from the lagged daily P&L stream; no look-ahead) or via `ewma_realised_vol`. `w1 = s * raw`. `portfolio_vol = sqrt(w' Σ w)` with the caller's annualised covariance is reported as a diagnostic only.
3. Long-only: negative weights set to 0.
4. Risk-contribution caps (source: risk, not notional). `RC_i = w_i (Σw)_i / (w'Σw)`. (a) Instrument: `RC_i <= max_instrument_risk_mult * handcraft_share_i`. (b) Class: `sum_{i in class} RC_i <= max_class_risk_share`. Enforcement by proportional down-scaling of the offending instrument or class, solving the scale factor by bisection so the cap holds AFTER the others are re-normalised, repeated to a fixed point (max 50 iterations, tolerance 1e-10; non-convergence raises). Never drops instruments. Uniform scaling in steps 5-6 leaves RC shares unchanged, so the caps still hold afterwards.
5. Gross cap: `sum|w| > max_gross` then scale all by `max_gross/sum|w|` (P3-06's `gross_cap_scale`, reused); `gross_cap_bound = True`. `max_gross` is validated at load: `<= 1.0` for ETF (no margin), `<= 4.0` for futures.
6. Margin (futures only): default `margin_limit = 0.30` of equity; if margin use exceeds it, scale all down; ETF path: no-op.
- Idempotence holds for `apply_caps` (steps 3-6, given fixed weights), not for `apply_limits` (s depends on sigma_ewma, a state outside the function).
- Correction vs source: none intended, the source's limits are all carried: 1.5x scale cap, gross 1.0x ETF / 4x futures, instrument risk <= 2x weight share, class risk <= 40%, margin <= 30% (futures), slow EWMA. Implementation choices to record in the OD-16 register (cross-file, for P0-08): the EWMA span value, and the fixed-point/bisection rule for the risk caps. Under OD-17 the ETF path is capped at 1.0x, so tau is frequently unreachable; the gross-cap fraction is reported, not hidden.

## Tests & acceptance criteria
`tests/test_risk_limits.py`:
- `test_forecast_proportionality_preserved`: halving all raw weights halves post-limit weights when no cap binds.
- `test_vol_scale_capped_at_1p5`: tiny `sigma_ewma` gives s == 1.5 exactly.
- `test_vol_scale_converges_to_half`: on a synthetic series whose realised vol is 2x tau, `ewma_realised_vol` + `vol_scale` converge to 0.5 within the span-implied horizon.
- `test_gross_cap_binds_and_flags`: low-vol assets, ETF limits, give `gross_cap_bound True`, `sum|w| == 1.0`.

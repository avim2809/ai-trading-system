# P4-05 — Fractional Kelly sanity bound

**Phase:** P4 **Status:** NEW (source ticket P4-05) **Depends on:** P1-02 **Touches live services:** no **Owner decisions:** none

## Rationale (cite source plan / literature)
Source P4-05: use fractional Kelly as an upper sanity bound on risk, not as a sizing rule: the target vol tau must not exceed 0.5 times the Kelly-implied vol, computed from a haircut Sharpe (source: 'deflated, haircut'). Literature: Kelly (1956); Thorp (2006) on fractional Kelly; Carver on using half-Kelly as a ceiling; Bailey and Lopez de Prado (2014) for the deflated Sharpe. Full-Kelly volatility for a Sharpe ratio S is S (in annual units), i.e. optimal leverage f* = S / sigma and optimal portfolio vol = S.

## Algorithm notes / pseudocode (keep the source plan's formulas exactly where they apply; correct them explicitly if wrong, with reason)
- `S_plan = (1 - haircut) * max(SR_backtest, 0)`.
- `vol_kelly = S_plan` (for a Sharpe in annual units and Gaussian returns the growth-optimal vol equals the Sharpe).
- Bound: `tau <= kelly_fraction * vol_kelly`, with `kelly_fraction = 0.5` per source.
- Example for the docstring: SR_backtest=0.4, haircut 0.5 gives S_plan 0.2, vol_kelly 0.2, max_tau 0.10. Note this means a tau of 12-15% (source value) would fail for modest Sharpe, which is consistent with OD-17 setting tau around 8-10% for the ETF path. The check is enforced (see reconciliation) and honest about this.
- Edge cases: non-positive backtest Sharpe gives max_tau 0 and `ok False` for any tau > 0 (a candidate with no edge cannot justify any risk); haircut outside [0, 1) raises; the charter minimum haircut (0.5) is enforced by the caller's config check, tested here with a `min_haircut` argument default 0.5.
